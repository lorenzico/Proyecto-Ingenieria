🎥 Proyecto de Ingeneria - V2 Cines
🧠 Descripción
Este proyecto consiste en el desarrollo de un sistema moderno y mejorado de reservas de entradas de cine, similar al de plataformas actuales como Cinesa, pero con una interfaz más intuitiva y funcional. La solución está pensada para ser clara, rápida y fácil de usar tanto para clientes como para empleados del cine.

🚀 Objetivo
Ofrecer un servicio digital eficiente que permita a los usuarios:

Consultar carteleras de películas actualizadas

Reservar asientos en un mapa interactivo

Gestionar sus reservas de forma sencilla

Pagar sus entradas mediante una pasarela de pagos segura

👤 Tipos de usuarios
Cliente: Consulta carteleras, reserva y paga entradas, gestiona su perfil y reservas.

Dependiente: Valida entradas, gestiona reservas y asistencia.

Administrador: Control total sobre la cartelera, salas, sesiones y gestión de usuarios.

🛠️ Tecnologías
Lenguaje: Java

Interfaz gráfica: Swing

Estructura: Proyecto modular con clases separadas por roles y funcionalidades

🔁 Metodología
Scrum con sprints de 2 semanas

Ciclo de vida iterativo e incremental

Duración estimada del desarrollo: 3 meses

✅ ¿Por qué nuestro sistema?
Mejor experiencia de usuario

Gestión más eficiente para empleados

Seguridad en las reservas y pagos

Escalable y fácil de mantener
